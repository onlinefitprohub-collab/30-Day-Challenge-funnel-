# Challenge Funnel Helper — Chrome Extension

Injects exported GHL page JSON files directly into the GoHighLevel page builder.

## Setup

1. Go to `chrome://extensions` and enable **Developer Mode**
2. Click **Load unpacked** and select this `chrome-extension/` folder
3. The extension icon will appear in your Chrome toolbar

> **Icons**: Add `icons/icon16.png`, `icons/icon48.png`, and `icons/icon128.png` before publishing. Any placeholder PNG will do for local testing.

## Usage

1. Export page JSON files from the funnel builder app (click **Export GHL**)
2. Open GoHighLevel → navigate to the funnel page you want to import
3. Click the extension icon
4. Click **Load Files** and select the exported JSON file(s)
5. Click **Inject** next to the page you want to inject
