Replace the entire write-in-place block in background.js with this logic:

Step 1 — Deep-clone AI sections:

var aiSections = JSON.parse(JSON.stringify(pd.sections));

Step 2 — Update the 3 metadata fields on each section to match the target page:

var targetPageId = existing.id;
var targetFunnelId = objectPath.split('/')[1];
var targetLocationId = (existing.sections && existing.sections[0] && existing.sections[0].locationId)
  ? existing.sections[0].locationId
  : '';

for (var si = 0; si < aiSections.length; si++) {
  aiSections[si].pageId = targetPageId;
  aiSections[si].funnelId = targetFunnelId;
  if (targetLocationId) aiSections[si].locationId = targetLocationId;
  aiSections[si].sequence = si;
}

Step 3 — Build write payload using existing top-level fields (theme, styles, fonts) but AI sections:

var writePayload = JSON.parse(JSON.stringify(existing));
writePayload.sections = aiSections;

This keeps general (colors, fonts), pageStyles (CSS variables), fontsForPreview, settings, trackingCode from the existing page — preserving the visual theme — while replacing the entire section/element structure with the AI-generated page.
