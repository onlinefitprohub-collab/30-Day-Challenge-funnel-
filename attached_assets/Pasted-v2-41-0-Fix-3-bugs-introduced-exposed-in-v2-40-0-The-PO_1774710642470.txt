v2.41.0 — Fix 3 bugs introduced/exposed in v2.40.0

The POST /funnels/builder/prebuilt-section/sync/changes endpoint is now confirmed working (returns 201). However 3 bugs are blocking the page from actually loading in the builder:

Bug 1 — SyntaxError in inject script (extension is broken)

The console shows:

Uncaught SyntaxError: Unexpected token 'const'
chrome-extension://…clonelevel-inject.js:1

A syntax error was introduced in v2.40.0 in the inject script. Find and fix it — likely a const/let declaration used in a context that doesn't support it (e.g. inside a switch without braces, or at the top level of a content script running in strict mode). Check clonelevel-inject.js line 1 and surrounding context.

Bug 2 — Change write: false to write: true in the sync/changes payload

Currently the A5 step sends:

{ "write": false, ... }

GHL accepted it (201) but didn't persist the data to Firebase. The builder then calls data?pageId=NaKUaWZ1OzCQYr3mx7PA and gets 500 errors because there's nothing to serve. Change to:

{ "write": true, ... }

This should tell GHL to actually write the page data to its storage backend.

Bug 3 — Top-level id field missing from injected page payload

The roundtrip test shows the injected page data no longer contains a top-level id field:

# v2.40.0:
payloadId=missing
topLevelKeys: ["sections","settings","general","pageStyles","trackingCode","fontsForPreview","popups","popupsList"]

# Expected (all previous versions):
topLevelKeys: ["sections","settings","general",...,"id"]

Ensure the page data object sent to both Firebase and the sync/changes endpoint includes id: pageId at the root level. This field was present before v2.40.0 and was likely dropped during the refactor.

What's working — do not change:

A5 POST /funnels/builder/prebuilt-section/sync/changes — keep this, just change write: false → write: true
Firebase write (A2) — keep as fallback
patchToken — keep as fallback
locationId extraction from tab URL — working correctly
Bump to v2.41.0.
